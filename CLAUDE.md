# CLAUDE.md

Code design and conventions (including test style): [DESIGN.md](./DESIGN.md).

## Language

Code comments and `.md` files are always written in English.

## TODO.md

`TODO.md` doubles as a changelog/backlog. Format:

- flat list, one item per line: `- [ ] N [tag] description`;
- new items go on top;
- status: `[ ]` (open) / `[x]` (done);
- on publish, insert a `# version X.Y.Z` marker at the top and keep accumulating below it.
